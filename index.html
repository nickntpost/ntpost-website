flame suite & cloud

Autodesk Flame is the industry-standard software for high-end VFX and finishing. As well as its own fully licensed Flame suite, set up for 4K with high-speed NVMe RAID storage, NT Post can add extra Flame workstations in the cloud on Amazon Web Services (AWS), so more artists can work on a show at the same time. It means a tight schedule or a high shot count can be met without waiting for space at a facility. Cloud seats are added for as long as a project needs them. Media can also be held in Amazon S3, AWS’s cloud storage, when a project calls for it. It scales to whatever a show needs, is encrypted by default and is built for 99.999999999% durability, so rushes, plates and shots stay safe and secure.
